CONFIGURATION PARAMETERS:
- try_nhc: Enable/disable (default: false)
- nhc_chi2_multipler: Chi-squared test multiplier (default: 1.0)
- nhc_max_velocity: Max velocity threshold (default: 5.0 m/s)
- nhc_noise_multiplier: Noise scaling (default: 1.0)

CONSTRAINT FORMULATION:
Mathematical model: v_body_y = 0 and v_body_z = 0
Where: v_body = R_GtoI * v_global

Jacobians computed with respect to:
- Orientation (3 DOF)
- Global velocity (3 DOF)
